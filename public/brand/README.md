# Halaxis brand kit

This is the only logo folder. Files are served at `/brand/<file>`. PNG and ICO only. Do not add an SVG, and do not put another copy of these marks anywhere else in the repo.

`mark.png` is the official Halaxis monogram. The other images are that same mark, unchanged except for size or a white knockout. Do not redraw or recolor them. Colors, the tagline, and the paths are in `brand.json`.

## Which file to use

- `logo-full.png` — horizontal lockup: mark on the left, name on the right. Transparent, at least 1024px wide.
- `logo-full-white.png` — the same lockup in white, for dark backgrounds.
- `mark.png` — icon only. The site header uses this beside the existing wordmark.
- `mark-white.png` — icon only, white.
- `favicon.ico` and `favicon-32.png` — browser tab icon.
- `apple-touch-icon.png` — 180×180 Apple touch icon.
- `icon-192.png` and `icon-512.png` — manifest icons.
- `og-image.png` — 1200×630 link preview.

Leave the transparency. Do not flatten a mark onto a filled rectangle.
